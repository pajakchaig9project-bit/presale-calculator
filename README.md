# presale-calculator

A lightweight web calculator for service pricing simulation, with a strategy-oriented landing page for **SYNCERA PJ VALLEY**.

## Project structure
- `index.html` — main SYNCERA landing page + pricing calculator.
- `presale-calculator/index.html` — standalone calculator page.
- `docs/umads-enterprise-blueprint.md` — consolidated enterprise strategy blueprint from the provided assets and UMADS operating model.

## Quick start
Because this project is static HTML, you can open files directly in a browser.

For local serving:

```bash
python3 -m http.server 8080
```

Then open:
- `http://localhost:8080/index.html`
- `http://localhost:8080/presale-calculator/index.html`
